# Ticket 02: In-Memory Authoritative Database

Status: Draft

## Objective

Create the semantic reference for authoritative storage and atomic commits.

## Scope

- Storage interface.
- In-memory storage adapter.
- Atomic transactions and constraints.
- Ordered commit versions and commit log.
- Shared storage-adapter conformance suite.

## Out of scope

- Durable restart recovery.
- Browser persistence.
- Live relational query maintenance.

## Depends on

- Ticket 01: Core Schema and Value Contracts.

Detailed acceptance criteria will be defined before implementation.
