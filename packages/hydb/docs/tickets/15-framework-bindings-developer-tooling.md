# Ticket 15: Framework Bindings and Developer Tooling

Status: Draft

## Objective

Provide an idiomatic application-development experience and make HyDB’s internal behavior inspectable.

## Scope

- Framework-neutral subscription APIs.
- React provider and hooks.
- Query explain plans.
- Query and materialized-view inspection.
- Mutation prediction and reconciliation inspection.
- Dataflow graph and arrangement inspection.
- Structured metrics and diagnostic events.

## Out of scope

- Additional framework bindings unless prioritized later.
- Vendor-specific production monitoring integrations.
- Administrative application UI.
